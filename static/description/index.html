HR Hospital Management System

Comprehensive module for managing doctors, patients and medical history

Key Features:

  • Doctor Management: Support for mentors, interns and specialities.
  • Patient Cards: Automated age calculation, contact details and personal doctor assignment.
  • History Tracking: Full logging of personal doctor changes and patient visits.
  • Advanced Reports: Diagnosis and reassignments wizards with reports.

Developed as part of Odoo Learning School Core Blocks.
